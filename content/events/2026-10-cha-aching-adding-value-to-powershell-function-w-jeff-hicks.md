## Event Description

With a little education and experience, it is not especially difficult to write a PowerShell function. You might write a function to simplify a basic task for yourself, or for others. A function's purpose is to abstract the user's experience in running PowerShell code. Your function most likely includes parameters to make the code flexible and re-usable. However there are a few other features you can incorporate into your PowerShell function that will add value from the user's perspective. These are features that will raise the quality of your code and add a degree of professionalism.

In this session we'll look at three easy-to-use features that are often ignored, but are excellent additions to any code base. You will learn how easy it is to add verbose messaging to your function. This can not only serve the user, but also the function's author. Next, instead of using Write-Host lines to provide feedback on long running code, you should take advantage of Write-Progress. Finally, learning how to take advantage of the information stream allows your function to do even more. This will be a demo-heavy session that will help you level-up your PowerShell scripting game.
